# Objectif 
Créer une application Streamlit interactive pour explorer, visualiser et analyser les avis 
Facebook de Disneyland Paris à l'aide de techniques de traitement automatique du langage 
naturel (NLP). 

# Étapes réalisées 
1. Nettoyage des données (langue, texte vide) 
2. Analyse de sentiments avec BERT multilingue 
3. Comparaison des sentiments avec les notes 
4. Extraction de 5 thèmes via LDA 
5. Classement des avis par thème dominant 
6. Visualisations interactives avec Plotly 
7. Timeline des sentiments 
8. Nuage de mots généré dynamiquement 
9. Filtres personnalisés avec export CSV 

# Résultats clés 
• Nombre total d'avis analysés : 8474 
• Thèmes détectés : 5 
• Modèle de sentiment utilisé : nlptown/bert-base-multilingual-uncased-sentiment
